# LumoGo Backend

Backend aplikacji mobilnej LumoGo dla biegaczy i osób aktywnych.

## Stack
- Spring Boot
- Spring Web
- Spring Data JPA
- Spring Security
- Spring Validation
- Lombok
- H2 Database (runtime)

## Uruchomienie
1. `mvn spring-boot:run`
2. Aplikacja dostępna pod `http://localhost:8080`

## Endpoints
- `GET /api/health` - health check
